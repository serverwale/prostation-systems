Windows Server Licensing for a New Server: Cores, CALs and Edition Checklist

Windows Server is a separate purchase from the server hardware, and it is the line most often missing from a quote. This is a short checklist; the full guide is ProStation's Windows Server licensing guide for custom servers. It is general information based on Microsoft's published documentation, not licensing advice, so confirm the final count with an authorised Microsoft reseller.

How the count works

  • Per physical core. Standard and Datacenter are licensed by physical cores, not threads. Microsoft's terms set a minimum of 8 core licences per processor and 16 per server.
  • CALs on top. A Client Access Licence is needed for every user or device that connects. A 40-person office with 40 accounts needs 40 user CALs even if only 25 are online at once.
  • Remote Desktop is extra. Staff working in RDP sessions on the server also need Remote Desktop Services CALs, per Microsoft's documentation.
  • Virtual machines. A fully licensed Standard host covers two VMs; more means licensing the cores again for each extra pair. Datacenter covers unlimited VMs.

Common mistakes

  • Forgetting CALs, or RDS CALs for remote sessions.
  • Buying fewer than 16 core licences on a small CPU.
  • Assuming "Windows Server pre-installed" means the licence is included.
  • Comparing a quote that omits CALs against one that includes them.

Frequently asked questions

  • How many core licences does Windows Server need? — One per physical core, with a minimum of 8 per processor and 16 per server, per Microsoft's product terms. Threads do not count.
  • Do I need CALs as well as core licences? — Yes for most deployments. Standard and Datacenter both need a Windows Server CAL for each user or device that accesses the server, with some exceptions listed by Microsoft.
  • Is Windows Server included when a server is sold with it installed? — Not necessarily. Installed and licensed are different things. Ask for the licence to be quoted or confirmed in writing.
  • Standard or Datacenter? — Standard covers two VMs per fully licensed host and suits a few VMs. Datacenter covers unlimited VMs and pays off only when VM count grows. Get a quote for both.
  • Can I avoid Windows Server licensing? — If your applications do not depend on Windows, Linux, Proxmox or another open platform carries no per-core licence. Windows VMs on any host still need their own licences.
