Medium-Sized Business Server Planning Checklist: Workloads, Redundancy and Backup

A server setup for a company of a few hundred people is a plan, not one bigger machine: list the workloads, decide how many machines should share them, add redundancy where a failure would stop work, then size CPU, ECC memory, storage and network from your own measurements. This is a short checklist; the full guide is ProStation’s server setup guide for a medium-sized business in India. The 100 to 500 employee range is planning shorthand, not a legal definition, and nothing here is a ProStation benchmark.

Step 1: list the workloads

WorkloadWhat it stresses
Directory, DHCP, DNSLittle, but everything depends on it, so protect it first
File shares and archivesStorage capacity and network
ERP, accounting, databaseStorage latency, RAM, single-thread CPU; check the vendor’s own requirements
Virtual machinesRAM and CPU cores; add every VM, then leave headroom
Remote desktop sessionsRAM per session; Remote Desktop licences if Windows hosts them
Backup targetCapacity, sequential write speed; keep it on a separate machine

Step 2: one server, a standby or a cluster

DesignProtects againstStill exposed to
One server with RAID, dual PSU, ECC and a separate backupDisk, power-supply and memory faultsBoard or CPU failure
Primary plus a standby you restore or replicate toSingle-server failure, with some manual workFailover time and replication gaps
Three or more hosts with shared storageHost failure with automatic restartShared storage and network, unless duplicated

High availability is a system, not a switch. Proxmox VE’s documentation lists at least three cluster nodes and shared storage among its requirements, and Broadcom describes vSphere HA as hosts working together so virtual machines can restart on other hosts. Move beyond one server when an hour of downtime costs more than the second machine: see how to calculate the real cost of downtime, and the dual PSU guide.

Step 3: size in this order

  • RAM first for virtualization: every VM plus hypervisor overhead plus spare capacity. ECC DDR4 is standard in all ProStation tiers.
  • Cores from the workloads, remembering that Windows Server licensing counts physical cores.
  • Storage by type: NVMe for databases and VM disks, larger disks for archives.
  • Network: a 1 Gb/s link carries about 125 MB/s at best and 10 Gb/s about 1,250 MB/s, shared by everyone on it. See the 1GbE, 10GbE and 25GbE guide.

ProStation’s listed tiers (Starter: Intel Xeon E, 16–64 GB ECC DDR4; Pro: Intel Xeon Scalable, 64–256 GB ECC DDR4; Ultra: dual Intel Xeon Scalable, 256–512 GB ECC DDR4) are starting points on the servers page, and each can be changed in the customizer. For a typical virtualization host, see the virtualization use case.

Step 4: backup

CISA’s data backup guidance recommends the 3-2-1 rule: three copies of important data, on two different media types, with one copy offsite. Add one copy that ransomware on your network cannot reach, and test restores on a schedule. RAID is not a backup. Illustrative arithmetic, not a measurement: a 2 TB full backup over 1 Gb/s at the theoretical 125 MB/s takes about 4.4 hours, and about 27 minutes over 10 Gb/s.

Step 5: licensing, power and support

  • Windows Server is licensed per physical core, with a minimum of 8 core licences per processor and 16 per server, and most deployments also need a CAL per user or device. Standard covers two VMs per fully licensed host. Linux with Proxmox carries no per-core fee. See the Windows Server licensing guide.
  • Power and cooling: size the UPS to the real load; see UPS sizing for servers and workstations.
  • Data protection: India’s DPDP Act requires reasonable security safeguards against personal data breaches, so backup, access control and patching are part of the job.
  • Support: ProStation hardware carries a 1-year warranty with extended warranty available at additional cost, 24/7 support and on-site engineers in six cities. Details on the warranty page.

Questions to settle before you order

  • Which workloads and how many users? What does an hour of downtime cost?
  • Which systems need Windows Server, and are CALs in the quote?
  • Where are the second and third backup copies?
  • Is the network 10GbE end to end, and what power and cooling exist?
  • Who replaces a failed part, and how fast, in writing?

Frequently asked questions

  • What server does a medium-sized business need? It depends on workloads, user count and the cost of downtime. For many companies of a few hundred staff, one virtualization host with Intel Xeon Scalable processors, ECC DDR4 memory, NVMe storage and 10GbE, plus a separate tested backup target, is a sensible starting point.
  • Do I need a cluster for 200 to 500 employees? Not necessarily. A cluster needs several hosts, shared storage and skilled administration. If a few hours of downtime is tolerable, one well-built server with internal redundancy and a tested backup may be enough.
  • How many CALs does a 300-person company need? Windows Server needs a CAL for each user or device that accesses it, so 300 staff accounts means 300 user CALs, plus Remote Desktop Services CALs if they use remote sessions. Confirm the count with an authorised Microsoft reseller.
  • Is RAID enough to protect company data? No. RAID keeps a server running through a failed drive. It does not protect against deletion, ransomware or a site loss, so follow the 3-2-1 backup rule.
