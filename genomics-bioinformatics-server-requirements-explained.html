Genomics & Bioinformatics Server Requirements Explained

Genomics pipelines are limited by three things: how many CPU threads you can throw at alignment and variant calling, how much RAM the biggest step needs, and how much storage the data takes. A GPU is optional. This is a quick reference to the published numbers, so you can size a bioinformatics server from facts rather than guesses.

CPU: parallel work rewards cores

Alignment tools use many threads, and variant calling is commonly run as scatter-gather: the work is split into independent pieces (genomic intervals or samples), run in parallel and merged. That favours a many-core server CPU with enough memory per job over a few very fast cores. For a throughput target of many genomes per week, a dual-socket platform is the usual direction; see choosing a CPU for AI and render workstations for how core count and clocks trade off.

RAM and ECC

Size RAM for the largest single step (the 84 GB index build is one example) and for how many jobs you want running at once. Pipelines run for many hours, which is the case ECC memory is designed for; read ECC RAM explained.

Storage: plan three tiers

  • Fast scratch (NVMe) for alignment, sorting and calling, where intermediate files are large. See SSD vs HDD for workstations.
  • Bulk working storage (HDD array) with redundancy; read RAID for workstations and remember RAID is not a backup.
  • Archive and backup on a separate machine; see the custom NAS and storage server guide. Converting finished BAMs to CRAM keeps this tier affordable.

Do you need a GPU?

Not for common CPU-based tools. A GPU helps only if you run GPU-accelerated pipelines such as NVIDIA Parabricks, whose requirements are in the table above. If you also do machine learning on the same machine, see GPU workstation vs server and PSU sizing for multi-GPU builds.

Putting it together

A genomics server is built from the pipeline outward: many cores, ECC RAM above your largest step, three storage tiers, and a GPU only if your tools use one. FAQ

  • How much RAM does a genomics server need? — At least the largest step: BWA-MEM2 index building needs about 84 GB for the human genome, and Parabricks lists 100 GB for a 2-GPU system. Add working memory for parallel jobs.
  • How much storage per genome? — For a 30x human genome, roughly 100–200 GB as FASTQ, 80–100 GB as BAM and 30–60 GB as CRAM; sizes vary with pipeline.
  • Is a GPU required? — No; only for GPU-accelerated tools such as Parabricks, which needs at least 16 GB of GPU memory.
